
# Оно тебе надо

Проектная работа Яндекс Практикума.

## О проекте

Одностраничный сайт аукциона вещей, в которые никто не верил. На странице представлены карточки лотов, информация об аукционе и контактные данные.

## Технологии

- HTML5
- CSS3
- Flexbox
- CSS Grid

## Запуск проекта

Для просмотра сайта откройте файл `index.html` в браузере.
